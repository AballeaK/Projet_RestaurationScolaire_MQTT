# Projet_RestaurationScolaire_MQTT
## Système IoT – Suivi et Gestion des Ordures

Projet fait dans le cadre du BTS CIEL IR (Lycée La Croix Rouge La Salle, Brest).

## Introduction
Mise en place d’une infrastructure complète de collecte, de transmission et de stockage des données des balances connectées pour la restauration scolaire.

## Technologies utilisées - **Broker MQTT :** Mosquitto (sécurisé avec TLS/SSL et ACL) - **Base de données :** MariaDB (modélisation MCD/MLD, intégrité référentielle) - **Traitement :** Python (ingestion en temps réel, validation des payloads JSON) - **Environnement :** Conteneur Proxmox
