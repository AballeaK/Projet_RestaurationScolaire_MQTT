# Projet_RestaurationScolaire_MQTT
Mon projet de gestion des déchets destinée à la cantine. J'ai mis en place l'intégralité du système pour gérer les flux de pesée : un broker Mosquitto MQTT opérationnel sur Proxmox afin de capter les données en direct, accompagné d'une base de données MariaDB pour les archiver de manière ordonnée.
